# Zaya.UI

Avalonia editors for `SettingDescriptor` from Zaya.Primitives.

## Package

| Package | Role | Who references |
|---------|------|----------------|
| **Zaya.UI.Impl** | Setting row/table editors and `SettingDescriptorListControl`. | **Host only** |

The host supplies Fluent theme and styles for `settings-row` / `settings-divider`. Chrome strings (validation, table add/remove) ship in this package.

See [versioning](docs/versioning.md) and [CHANGELOG](CHANGELOG.md).
